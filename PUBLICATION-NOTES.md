# Publication notes

This unofficial Simplified Chinese source distribution retains the application code, build configuration, assets and AGPL-3.0-only license with attribution to Amos Blomqvist.

The upstream tests directory is excluded from this distribution because it contains real learning-session-derived data, graph records, local paths, provenance metadata and a test TLS private key. The npm test command will not work against this distribution. No application tests or Windows installer execution are claimed.

The supplied Windows installer predates the corrected GitHub update destination. Its embedded update configuration has not been verified; disable automatic updates to avoid an English upstream replacement.
