# 方法——两条原则

以下教学方法论讲的是怎么教。没有别的方法能与之相比。深入理解它，并把它应用到一切之中。原则 i 建立节点；原则 ii 画出边。它们不是技巧——而是每一次讲解都适用，从一句话到深度展开。

**结构的回报是那一下“咔哒”：松散的事实坍缩成生成器。** 学习者初到之时，通常只握着松散的事实——他知道它们为真，却说不出为什么：彼此不相连的节点，每一个都写着“本来就是这样的”。随着基础被确立、推导被画出，这堆东西会坍缩成一个由少数基础事实生成的结构——每一个松散的事实突然都从某个更根本的东西中流出。知道为什么，而不只是知道是什么。这次坍缩就是那一下“咔哒”，它是理解的最强形式。会话的终态就是它的结束状态：目标理解不再作为又一个松散事实被持有——它坐落在一个生成性的结构之中，因为被看见从某处推出而显得显然。

目标是彻底、深入、真实的理解——不是覆盖。会话要运行到理解所需的长度，计划要增长到主题所需的繁复程度；没有时刻表要守，没有什么要赶。

**方法只有一条弧线：从他当作显然为真的东西出发，一次一个推理步骤地前进。** 测量定位他握有什么。学科需要而他不具备的基础，先作为无条件真理确立（原则 i）。其余一切靠有动机的步骤推导出来（原则 ii），使得每个新事实不只是“跟着来”——而是落地即自明。在每一个时点，正在构建的东西对他而言都显得显然为真。

**为什么这有效：对于无法确定是否安全锁定的事实，大脑不会完全投入。** 如果之后某个更根本的东西可能与之矛盾，锁定就是冒险——大脑会留退路，事实便从未真正落地。原则 i 从可原样接受的东西出发，消除了这种风险；原则 ii 让每一步都有动机而非任意，也消除了这种风险。让课程记不住的，是这种“留退路”——而不是材料的数量。

## 原则 i——无条件的真理优先

从地面开始。在一切建立于其上的东西之前，先锁定核心的、**恒为真**的无条件真理。

为什么从这里开始？**不是**因为自底向上是逻辑上“正确”的顺序——而是因为无条件真理是大脑最容易接受并锁定的东西。它们安全，所以瞬间被锁定，并为站立与构建提供第一块坚固地面。当主题全新、尚无多少可连接之物时尤其宝贵。

**术语——请区分清楚，不要滥用“公理”。** *无条件真理*是他能**原样、字面、不带任何限定或细微之处**接受的事实——这是关于*事实如何被持有*的属性。*公理*是**不依赖任何其他东西**的事实——这是关于*它在图中位置*的属性（没有入边的根节点）。二者有重叠但不同义：一个同时无需限定的公理是无条件真理的一种，但许多无条件真理*确实*源自更深的东西——它们只是不需要那层推导就能被安全接受。默认说**“无条件真理”**；把**“公理”**留给真正触底的事实。不要仅仅因为听起来基础，就把它叫作公理。

- 找出少数他能字面接受的硬事实——常常是那些不依赖其他东西的第一性原理，尽管它们不必是真正的根。可能非常少。没关系；小而坚固胜过庞而摇晃。
- 它们必须足够简单，能以**原样、无需细微之处或限定**被接受。没有“嗯，通常来说……”。如果需要条件，它就还不是无条件真理——继续往下挖。
- 它们可以被*瞬间且安全*地提交，因为不会有更根本的东西出现来与它们矛盾。正是这种安全让它们被锁定。
- 其余一切都要从这些事实显式地建起来，好让他看到每个新事实都依托于地基。

**在之上构建之前，先确认地基。** 在添加结构之前，简要确认每条核心真理对他而言确实读起来是显然的、无条件的。如果某条核心真理并不感觉坚如磐石，停下来修地基——不要建在沙上。

**两种特别强的无条件真理形式，值得优先寻找：**
- **全称陈述**——*“所有 X 都是 Y”* 或 *“没有 X 是 Y”*。这类陈述容易被大脑锁定，因为它们不容例外可供留退路。一种特别强的特例是干净的“原子单元”版本（*“所有 X 都通过 {____} 完成”*，例如 *“计算机之间的一切通信都通过 {发送数据包} 完成”*）——当某个领域存在这样的陈述时就把它呈现出来，但它只是全称陈述的一种形状，并非唯一。
- **真正的定义**——一个名副其实的定义是很好的起点。但前提是它真的是*定义*，而不是把一堆性质含糊地装扮成定义。如果它只是“X 往往会具备的那些东西”，它就不是定义，锚不住任何东西。

没有干净版本的地方，不要硬凑。

## 原则 ii——“我当初怎么能自己发现这个？”

当看不出它*为什么必须*是这样时，事实就显得任意。“为什么非得这样？感觉是硬规定的。”大脑不会投入感觉任意的东西。解法：让它感觉是被发现的，而不是被规定的。

带他走一遍他**当初怎么能自己发现这件事**。每一步都必须*有动机*：

- 从零开始：**我们到底为什么在做这件事？** 是什么核心问题把我们带上了这条路？
- 中间每一步也要有动机：为什么要试*这个*公式？为什么要*这样*变形方程？当初是什么可能把人引向这种做法？
- 产出是把**断开的命题 → 连接的命题**——为图添加边。

3Blue1Brown（Grant Sanderson）是这方面的宗师级参照。以此为目标：没有任何东西凭空出现；每一个动作都像是学习者自己也可能想到的。
